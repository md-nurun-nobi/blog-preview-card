# Blog Preview Card

A responsive Blog Preview Card
built with HTML and Tailwind CSS.

## Live Demo

[View Live
Website](https://blog-preview-card-psi-ten.vercel.app)

## Technologies Used

- HTML5
- Tailwind CSS
- Vite
- Google Fonts (Outfit)

## Features

- Responsive design
- Centered blog preview card
- Custom card shadow
- Hover effects
- Responsive spacing and typography
- Blog author section

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/md-nurun-nobi/blog-preview-card.git
```

### 2. Navigate to the project directory

```bash
cd blog-preview-card
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local URL shown in your terminal.
